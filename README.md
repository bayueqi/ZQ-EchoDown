# ZQ-EchoDown

EchoMusic 的音乐下载插件：把正在播放的歌曲，或播放队列里的整批歌曲，下载到本地目录。

## 功能

- **单曲下载**：歌曲右键「下载到本地」，或播放栏「⋯」更多菜单里的「下载当前歌曲」。
- **批量下载**：侧边栏「批量下载」页列出当前播放队列，勾选 / 全选后一键下载；播放栏右侧也有「批量下载」入口。
- **音质选择**：标准 128k、较高 320k、无损 FLAC、Hi-Res，资源不可用时自动回退到较低音质。
- **任务中心**：每首歌一个任务，显示进度、支持单独取消；批量下载并发 2 个，其余自动排队。
- **文件命名**：`歌手 - 歌名.ext`，自动处理 Windows 保留字符与设备名，重名自动改名，已存在则跳过。

## 安装

1. 下载本仓库（Code → Download ZIP 或 `git clone`）。
2. 把 `manifest.json`、`index.js`、`icon.svg` 放进 EchoMusic 的插件目录：
   `%APPDATA%\echo-music\plugins\ZQ-EchoDown\`
3. 在 EchoMusic 的插件管理里启用「ZQ-EchoDown」。

要求 EchoMusic `>= 2.3.2-beta.10`（需要 `downloads` / `localFiles` / `kugouApi` 能力）。

## 使用

1. 打开插件设置，选择保存目录和默认音质。
2. 播放需要下载的歌曲，让它们进入播放队列。
3. 侧边栏进入「批量下载」，勾选要下载的歌曲，点「下载选中」。

## 说明

- 下载沿用宿主网络与系统代理；如果出现 `net::ERR_BLOCKED_BY_CLIENT`，通常是系统代理或广告拦截软件拦截了酷狗 CDN 域名，把相关域名设为直连即可。
- 插件只负责下载，不提供音源、不破解版权内容，请自行确认使用场景合法。
